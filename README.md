# 🍾 Message Bottle ✨

A cute website to leave adorable messages for your friend! Open the bottle to reveal one message at a time.

## Features
- 🏖️ Beautiful gradient design
- 💌 Multiple messages to reveal one at a time
- ✨ Smooth animations
- 📱 Mobile responsive
- 🎨 Customizable messages

## How to Use

1. **Customize Messages**: Edit the `messages` array in `script.js` with your own cute messages
2. **Open Bottle**: Click the "Open Bottle" button
3. **Read Messages**: Click "Next Message" to see the next one
4. **Close Bottle**: Click "Close Bottle" to reset

## Deployment

### Option 1: GitHub Pages (Free & Easy!)
1. Go to your repository settings
2. Scroll to "GitHub Pages"
3. Select `main` branch as source
4. Your site will be live at `https://jocelyncw2007-creator.github.io/message-bottle`

### Option 2: Vercel
1. Connect your GitHub repo to Vercel
2. It deploys automatically!

### Option 3: Netlify
1. Connect your GitHub repo to Netlify
2. Drag and drop the folder or connect Git

## Customization Ideas

- Change the gradient colors in `style.css`
- Add more messages to the `messages` array
- Modify the bottle design with different colors
- Add sound effects
- Add emojis to each message
- Create themed bottles for different occasions
